# ThingsBoard IoT Dashboard — Приточно-вытяжная установка (ПВУ)

## Что сделано

### 1. ThingsBoard Community Edition в Docker

Поднят ThingsBoard CE через `docker-compose` с:
- сохранением данных через volumes (`~/.mytb-data`, `~/.mytb-logs`)
- переменными окружения (`TB_QUEUE_TYPE=in-memory`)
- политикой перезапуска (`restart: always`)

### 2. Эмулятор приточно-вытяжной установки

Написан эмулятор на Python (`emulator.py`), который отправляет телеметрию в ThingsBoard по HTTP API каждые 5 секунд.

**Параметры телеметрии:**
- `temp_supply` — температура приточного воздуха (°C)
- `temp_outdoor` — температура наружного воздуха (°C)
- `temp_setpoint` — уставка температуры (°C)
- `fan_supply_rpm` — обороты приточного вентилятора (RPM)
- `fan_exhaust_rpm` — обороты вытяжного вентилятора (RPM)
- `filter_pressure_diff` — перепад давления на фильтре (Па)
- `damper_position` — положение воздушной заслонки (%)
- `heat_valve` — клапан нагрева (%)
- `cool_valve` — клапан охлаждения (%)
- `humidity` — влажность (%)
- `is_running` — статус работы (true/false)
- `is_alarm` — авария (true/false)
- `filter_clogged` — засорение фильтра (true/false)

**Реалистичная физика:**
- Температура приточного воздуха плавно подтягивается к уставке
- Клапан нагрева открывается пропорционально отклонению от уставки
- Фильтр постепенно засоряется — давление растёт со временем
- При давлении > 250 Па срабатывает авария засорения фильтра
- Все значения имеют случайный шум для реалистичности

### 3. Дашборд в ThingsBoard

Собран дашборд **PBU Ahu-01** с виджетами:
- График температур (приточная, наружная, уставка)
- График перепада давления на фильтре
- Карточки текущих значений: влажность, обороты вентиляторов
- Индикаторы статусов: авария, засорение фильтра

## Запуск

### Требования
- Docker Desktop
- Python 3.x

### 1. Запустить ThingsBoard
```bash
docker compose up -d
```
Подождать 3-5 минут пока запустится. Открыть: http://localhost:8080

Логин: `tenant@thingsboard.org` / Пароль: `tenant`

### 2. Создать устройство
- Devices → + → Название: `AHU-01`
- Скопировать Access Token из вкладки Credentials

### 3. Запустить эмулятор
```bash
python3 emulator.py
```

## Структура проекта
thingsboard-iot/
├── docker-compose.yml # ThingsBoard CE + volumes + restart policy
└── emulator.py # Эмулятор ПВУ с реалистичной физикой

## Сложности

- ThingsBoard при первом запуске требует очистки volumes если прервать установку
- Токен устройства нужно получать из интерфейса после создания устройства
- Кнопка Add в виджете активируется только когда устройство уже отправляет данные
